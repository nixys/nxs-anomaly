# Legacy-пул NXS

## Подготовка установки

Нужны работающие API и воркер nxs-anomaly, права редактора, тестовый получатель и доступ к настройкам отправителя. Из сети отправителя проверьте публичный HTTPS-адрес и сертификат. [Установка nxs-anomaly](INSTALLATION.md).

## Подключение отправителя

1. В nxs-anomaly создайте цепочку с уведомлением тестового пользователя. В разделе «Интеграции» создайте тестовую интеграцию типа `webhook`, назначьте цепочку по умолчанию и скопируйте ключ.
2. В существующем отправителе nxs-alert укажите /v2/alert/pool. Передайте ключ интеграции в заголовке X-Auth-Key. Задайте triggerMessage и monitoringURL. Перед подключением рабочего пула проверьте каналы по умолчанию.
3. В тестовой оболочке задайте API с базовым адресом установки и KEY с ключом интеграции. Выполните запрос ниже из сети отправителя.

```bash
curl --fail-with-body -i -X POST "$API/v2/alert/pool" \
  -H 'Content-Type: application/json' \
  -H "X-Auth-Key: $KEY" \
  --data-binary '{"triggerMessage":"Checkout test","monitoringURL":"https://monitor.example.org/checkout","alertChannel":"email"}'
```

## Проверка жизненного цикла

Ожидайте HTTP 200 с message success. Сверьте заголовок группы с первой строкой сообщения и проверьте адресатов. Обработчик создаёт событие firing. Закройте тестовую группу в интерфейсе. В истории группы проверьте выполнение выбранной цепочки и сопоставьте попытку доставки с уведомлением у адресата.

До переключения отправителей проверьте выбор каналов legacy-пула. Обработчик всегда добавляет email. Если нет ни telegram, ни call, он добавляет оба канала. Используйте отдельного получателя и после проверки каналов закройте группу в интерфейсе.

## Эксплуатация и диагностика

При неверной группировке или отсутствии доставки сравните поля и метки события с предпросмотром маршрута. При 404 проверьте полный путь и действующий ключ. При 503 учитывайте Retry-After. После ротации ключа сразу обновите отправитель и повторите тест. [Маршруты и уведомления](CONFIGURATION.md) · [Преобразование полей](ALERT_PROCESSING.md) · [Ответы HTTP](API.md).
