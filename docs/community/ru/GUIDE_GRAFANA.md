# Дашборд сервиса в Grafana

## Перед началом

Сначала настройте сбор метрик API и воркера в Prometheus. Получите права на настройку источника данных и импорт дашбордов Grafana. [Подключение Prometheus](GUIDE_PROMETHEUS.md). [Способы установки](INSTALLATION.md). [Установка Grafana](https://grafana.com/docs/grafana/latest/setup-grafana/installation/).

## Подключение и настройка

1. Добавьте источник данных Prometheus с URL, доступным серверу Grafana.
2. Сохраните и проверьте соединение.
3. Импортируйте JSON дашборда из поставки, выберите источник Prometheus и сохраните в папке команды. [JSON дашборда](../../grafana-dashboard.json).

```text
up
```

## Проверка и устранение неполадок

Выполните запрос в Explore для этого источника. Отправьте тестовый алерт и проверьте панели приёма и доставки за последние 15 минут. При No data проверьте интервал времени, цели сбора и выбранный источник. Перед повторным импортом сохраните локальные изменения дашборда.
