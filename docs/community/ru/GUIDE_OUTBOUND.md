# Исходящий HTTP webhook

## Перед началом

Подготовьте HTTPS-приёмник для JSON формата Alertmanager. Выберите способ авторизации воркера. Для внутреннего сервиса разрешите адрес в политике исходящей доставки и проверьте DNS и TLS из сети воркера. [Способы установки](INSTALLATION.md).

## Подключение и настройка

1. Добавьте шаг ниже в тестовую цепочку.
2. Поместите полное значение заголовка Authorization в указанный секрет окружения, назначьте цепочку интеграции и отправьте подходящий алерт.

```json
{"kind":"TRIGGER_WEBHOOK","webhook_url":"https://hooks.example.org/alerts","headers":{"Authorization":"env:NXS_ANOMALY_GATEWAY_AUTH"}}
```

## Проверка и устранение неполадок

Сверьте тело запроса на приёмнике с алертом в истории группы и код HTTP в попытках доставки. При 401 проверьте ссылку на секрет заголовка, при `blocked_destination` — разрешённые адреса. Предусмотрите повторную доставку при потере ответа.
