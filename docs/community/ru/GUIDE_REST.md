# Автоматизация через REST API

## Перед началом

Установите HTTP-клиент, например curl. Получите HTTPS-адрес и ключ с минимальной ролью для выбранной операции. На собственном клиенте добавьте CA сервера в доверенное хранилище. [Способы установки](INSTALLATION.md).

## Подключение и настройка

1. Задайте в окружении базовый URL в API и ключ в API_KEY.
2. Прочитайте первую страницу списка команд запросом ниже.
3. Для больших списков увеличивайте offset на limit, пока не получите total записей.

```bash
curl --fail-with-body -H "X-API-Key: $API_KEY" "$API/api/v1/teams?limit=10&offset=0"
```

## Проверка и устранение неполадок

Сверьте items и total с интерфейсом при тех же правах. При 401 проверьте ключ, при 403 — роль и команду. Перед записью сверьтесь со схемой операции и сохраните ID объекта из ответа для последующих изменений.
