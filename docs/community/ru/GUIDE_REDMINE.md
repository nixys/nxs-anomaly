# Создание задач в Redmine

## Перед началом

Включите REST API Redmine. Дайте служебной учётной записи право создавать задачи в нужном проекте и получите API-ключ. Проверьте доступ воркера к базовому URL Redmine. [Способы установки](INSTALLATION.md). [Установка Redmine](https://www.redmine.org/projects/redmine/wiki/RedmineInstall).

## Подключение и настройка

1. Запишите ключ в переменную окружения, имя которой указано в token_env.
2. Добавьте шаг ниже в цепочку и замените project на идентификатор проекта.
3. Укажите базовый URL, адаптер добавит /issues.json.

```json
{"kind":"CREATE_ISSUE","tracker_type":"redmine","url":"https://redmine.example.org","project":"checkout","token_env":"REDMINE_API_KEY"}
```

## Проверка и устранение неполадок

Отправьте один тестовый алерт. Проверьте попытку доставки и откройте новую задачу в Redmine, сверьте проект, тему и описание. При 403 проверьте права на проект, при 422 — обязательные поля трекера. Перед повторной отправкой проверьте обе системы.
