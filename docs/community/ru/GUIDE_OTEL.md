# Экспорт трасс по OTLP/HTTP

## Перед началом

Подготовьте коллектор с HTTP-приёмником OTLP, цепочкой traces и доступом к хранилищу трасс. Проверьте сеть и доверие к сертификатам от API и воркера. Получите данные авторизации коллектора, если они нужны. [Способы установки](INSTALLATION.md). [Установка Collector](https://opentelemetry.io/docs/collector/installation/).

## Подключение и настройка

1. Задайте параметры ниже для обоих процессов.
2. SDK добавит /v1/traces к базовому URL.
3. Для полного адреса используйте OTEL_EXPORTER_OTLP_TRACES_ENDPOINT.
4. При авторизации поместите `OTEL_EXPORTER_OTLP_HEADERS` в Secret и перезапустите процессы.

```dotenv
OTEL_EXPORTER_OTLP_ENDPOINT=http://otel-collector:4318
OTEL_SERVICE_NAME=nxs-anomaly
OTEL_TRACES_SAMPLER_ARG=1
```

Передайте параметры через окружение сервиса. В Helm используйте extraConfig для открытых значений и Secret приложения для ключей. После изменения окружения пересоздайте соответствующие процессы API и воркера.

## Проверка и устранение неполадок

Отправьте тестовый алерт с доставкой. Найдите в хранилище service.name и сопоставьте spans приёма и доставки по связи между ними. Если видна лишь часть, проверьте настройки обоих процессов и экспорт коллектора. После проверки выберите частоту семплирования под рабочую нагрузку.
