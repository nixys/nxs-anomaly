# Прокси для доставки уведомлений

## Перед началом

Подготовьте прокси с поддержкой транспорта выбранного канала. Определите внутренние адреса для прямого доступа. [Транспорты прокси и каналы](PROXY.md). [Способы установки](INSTALLATION.md).

## Подключение и настройка

1. Задайте общие или поканальные параметры прокси у API и воркера.
2. Пример направляет Telegram через HTTP-прокси.
3. При необходимости внесите внутренние адреса в `NXS_ANOMALY_DELIVERY_NO_PROXY` и перезапустите процессы.

```dotenv
NXS_ANOMALY_DELIVERY_PROXY_TELEGRAM_URL=http://proxy.example.org:3128
```

Передайте параметры через окружение сервиса. В Helm используйте extraConfig для открытых значений и Secret приложения для ключей. После изменения окружения пересоздайте соответствующие процессы API и воркера.

## Проверка и устранение неполадок

Отправьте тест из интерфейса и уведомление из цепочки через воркер. Проверьте журнал прокси и попытки доставки. При таймауте проверьте ACL, поддержку CONNECT и DNS. После изменения исключений проверьте адреса с прямым доступом.
